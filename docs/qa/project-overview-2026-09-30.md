# 项目概览验证记录

## 实现

- 项目内增加“项目概览”标签页，默认四个模块，六个预设组件可选。
- 每个项目共用一份布局，仅项目管理员可修改，归档项目只读。
- 单/双列、1/2/4/6 模板、增删、顺序和组件宽度调整；支持 3/5 个组件。
- 统一统计当前未归档主任务，提供任务完成率、状态、未完成优先级、人员待办及关注任务。
- 按浏览器时区确定统计日期；图表下钻使用相同日期与过滤条件。
- 配置手动保存，页面进入/刷新时读取数据，无定时轮询。

## 验证结果

- `npm run typecheck`：通过。
- `npm run build`：通过，概览单独按需加载，未增加图表依赖。既有 Editor 包大小提示仍存在。
- `npm test`：10 个测试文件、88 项测试全部通过。
- 新增 7 项项目概览测试，覆盖主任务统计、超过一页的数据、归档/删除/子任务排除、关注并集、截止日期边界、时区跨日、权限/凭据、布局校验、幂等、并发版本与真实会话 HTTP 接口。
- `node scripts/browser-project-overview.mjs`：通过。模拟 API，不修改现有项目。覆盖图表下钻、清空筛选、任务详情关闭后保留筛选、模板、增删、排序、宽度、取消、保存、重载、冲突、只读角色、归档项目、空数据、失败重试及 360px 手机布局。
- 本地真实账号只读检查：概览 HTTP 返回与页面主任务总数一致，默认四个模块正常渲染。
- `git diff --check`：通过。
