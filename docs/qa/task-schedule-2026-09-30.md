# 任务日历与时间线验收

## 实现范围

- 项目 → 任务提供看板、列表、日历、时间线，共用现有筛选和详情抽屉。
- 月历周一开始，跨周延续任务条，超过三层通过当天弹窗查看。
- 时间线支持日/周刻度、日期定位、前后范围、今天与子任务缩进。
- 日期完整时按首尾包含的区间展示；只有开始或截止日期时按对应日期点展示；无日期任务独立展开并分页。
- 点击任务进入详情修改日期，点击“保存任务内容”后刷新当前排期。没有日期自动保存或定时轮询。
- 排期接口按区间相交查询，返回轻量任务摘要，每页 100 项，提供总数和加载更多，日期范围上限 120 天。
- 沿用项目成员、凭证范围、归档和只读权限；无需数据库迁移或新增依赖。

## 验证结果

- `npm run typecheck`：通过。
- `npm run build`：通过；现有 Editor 分包大小提示仍存在。
- `npm test`：11 个文件、96 项测试通过。新增 8 项覆盖日期交集、单日期、无日期、字面搜索和公共筛选、分页、手动保存后的范围变化、权限，以及跨周/闰年/夏令时排布。
- `node scripts/browser-task-schedule.mjs`：通过。使用模拟数据验证跨周任务条、日期与溢出弹窗、详情手动保存、未排期转排期、四种视图共享状态筛选、搜索与 URL 刷新、日周刻度、手机宽度、只读/归档、207 项分页和错误重试。共 55 次模拟排期读取，只有点击保存时出现 2 次模拟写入。
- `node scripts/browser-project-overview.mjs`：通过，保留概览钻取筛选、配置保存、权限及手机展示。
- 本地真实服务：登录后读取排期和未排期接口，核对页面数量，验证日历和时间线加载正常。所选项目当前无排期或未排期任务，此检查仅读取项目内容；有数据的交互由上述数据库测试和浏览器模拟覆盖。
- 已检查桌面和手机截图；页面无横向溢出，时间线在自身容器内滚动。浏览器未报告页面异常。
