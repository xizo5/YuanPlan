# 账号恢复与附件维护

适用版本：迁移 `0004_recovery_system_actor.sql` 及以后。命令在项目根目录执行，使用实例的环境变量。开发环境使用 `npm run ops -- ...`；已构建的运行环境使用 `npm run ops:production -- ...`。

## 账号恢复

### 用户自助找回

登录页选择“忘记密码”。配置 `SMTP_HOST`、`SMTP_FROM` 及所需 SMTP 认证后，已验证邮箱的账号可申请恢复邮件。未验证邮箱（包括无需邮箱验证注册和管理员建号）不能通过邮件找回，需联系实例管理员。公开接口对存在和不存在的邮箱返回相同提示；同一账号五分钟内只签发一次。邮件传输失败会作废此次链接并记录不含邮件内容或凭据的服务端事件。

未配置邮件时，界面提示联系实例管理员，不声称邮件已经发送。当前没有持久邮件重试队列；发送失败需修复 SMTP 后重新申请，五分钟限制仍适用。

### 管理员签发

实例设置 → 账号管理 → 生成恢复链接。管理员将链接通过受控渠道交给账号本人。项目管理员身份本身不具有实例账号恢复权限。

链接有效期为 30 分钟，只可使用一次。新链接使旧的未消费链接失效；成功重置会撤销该账号全部会话和 MCP 凭据。停用账号会使未使用恢复链接失效，重新启用后需重新签发。密码及原始令牌不会进入审计记录。

### 主机端紧急恢复

用于已有实例管理员忘记密码、无法进入管理页面的场景：

```powershell
npm run ops -- recover --email admin@example.com --reason "实例管理员无法登录，需要恢复访问"
```

生产构建中：

```powershell
npm run ops:production -- recover --email admin@example.com --reason "实例管理员无法登录，需要恢复访问"
```

命令只接受已有、未停用的实例管理员，不提升普通账号权限，不解封停用账号，也不直接设置密码。输出的 URL 是敏感凭据；不要复制到工单、共享日志或代码库。

此功能属于拥有服务器配置和数据库访问权限的主机运维边界，没有 HTTP 调用入口。审计记录使用禁用、无密码、无业务权限的系统身份，保存操作系统用户名、主机名、原因和目标账号；不会伪装成目标用户主动签发。该系统身份不参与首次安装判断，也不能从实例设置中启用。

## 附件维护

先预览，不修改文件：

```powershell
npm run ops -- files-clean
```

核对报告后执行清理，示例保留最近七天的未登记文件：

```powershell
npm run ops -- files-clean --older-than-hours 168 --apply
```

默认和最短保留期均为 24 小时。报告列出扫描数、数据库已登记数、近期文件数、跳过项、候选文件名和实际删除项。

清理范围仅为配置的 `UPLOAD_DIR` 直属普通 UUID 文件，不递归进入子目录、不跟随符号链接、不删除其他文件名。**所有数据库已登记附件都保留**，包括归档、回收站及历史版本引用的附件；本命令不用于清除业务历史。

上传事务持有共享维护锁，扫描/清理持有独占维护锁，防止把正在上传且元数据尚未提交的文件误判为孤立文件。删除前再次检查文件身份、大小和修改时间。文件系统或审计失败可能留下未登记文件；数据库提交回执丢失也不能据此断定事务未提交，因此上传失败路径不会立即删除文件，交由本命令在保留期后检查。

该协议要求部署中所有写入进程都运行此版本；升级时应先停止旧进程。运维期间不要让其他程序修改附件目录。大量文件扫描期间上传会等待维护锁，建议在低负载时执行。数据库与附件的一致备份、空环境恢复命令见[容器部署与备份指南](docker-and-backup.md)。

## 验证范围

- 集成测试使用独立 `_test` 数据库、临时附件目录和模拟 SMTP，不发送真实邮件。
- 覆盖令牌过期、重放、并发消费、旧会话/凭据撤销、系统身份边界。
- 覆盖审计故障导致密码/会话和任务/附件元数据回滚、磁盘写入失败、上传与清理互斥、历史附件保留。
- `scripts/browser-recovery.mjs` 使用临时测试账号验证页面流程，不重置本地管理员账号。
- 实际 SMTP 服务投递、磁盘硬件故障、进程崩溃和异机恢复仍需部署环境验收。
