# 我的任务分页与筛选

用户已确认：我的任务采用数字分页列表，默认每页 10 条，可选 20、50 条，显示筛选后的总条数。任务名称模糊搜索，状态和优先级单选筛选，三者组合生效；切换条件或每页数量回到第一页，并提供清空筛选。保留原有列表字段及任务详情跳转。

后端 `/api/my-tasks` 接收 query、status、priority、page、pageSize，先按当前用户任务归属、项目成员权限及未归档/未删除条件过滤，再计数和分页。名称搜索仅匹配标题并转义 LIKE 通配符。沿用截止日期优先排序，增加 ID 作为稳定排序依据；越界页回退到最后一页。

前端复用 Mantine 控件和现有列表样式。搜索防抖，筛选显示加载、失败、无匹配结果等状态；提供带可访问名称的分页与筛选控件，移动端列表局部横向滚动。

实施顺序：后端分页与参数校验 → 独立我的任务组件 → 数据库查询测试、类型检查与浏览器交互验证。保留工作区已有未提交修改，不进行无关重构。
