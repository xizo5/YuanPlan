# 子任务行为修正

用户已确认实施：项目看板、列表默认包含子任务；状态独立变化；支持在父任务中创建子任务和关联已有任务，支持解除父子关系。

- 同项目、一级层级，每个子任务仅有一个父任务。禁止关联自己、跨项目、含子任务的任务、已归档或删除任务；已关联任务必须先解除关系。
- 通过现有带版本检查和幂等键的任务更新接口变更 parentId。保留原编号、状态、负责人、评论和附件，记录历史；项目事务锁串行化关系变更。
- 看板排序范围扩展到同状态的所有活动任务，拖动不改变父子关系或级联状态。
- 列表平铺去重，显示父任务编号；看板显示父任务编号和标题；筛选面板提供隐藏子任务。
- 子任务编辑区独立组件，关系操作和新建后刷新外部视图。新增或关联子任务不覆盖父任务草稿，因此允许在未保存详情时操作。解除当前任务自身父子关系仍需先保存。
- 候选搜索支持编号、标题及分页；服务端过滤候选并在写入时再次校验。

验证：服务层关联/解除、层级与权限拒绝、并发版本、子任务拖动；浏览器验证新建后可见、关联/解除、隐藏子任务和详情跳转；最终类型检查与构建。
