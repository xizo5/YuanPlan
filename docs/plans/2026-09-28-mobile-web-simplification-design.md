# 手机网页简化设计

## 目标与范围

沿用现有 H5、账号、API 和权限。手机端以查看及处理任务为主，让 360–430px 屏幕无需横向滚动即可完成导航、查看任务、改状态和保存。桌面布局及功能保留。

## 方案选择

现有响应式布局已可打开，但导航占用首屏且任务列表是宽表格。优先在现有 React 页面加手机布局，不新增小程序或独立客户端。手机导航仅突出“我的任务”“我的项目”，团队、AI 集成和系统管理置于“更多”，仍可访问。项目任务在首次打开时默认列表，用户仍能手动切换看板。

我的任务与项目任务在手机上使用整行可点的紧凑列表，显示标题、项目或状态等最常用信息；桌面继续显示表格。任务详情保留完整内容和权限，压缩表单间距，不在手机上剥夺编辑能力。

## 验收

- 360、390、430、768px 均无整页横向溢出。
- 手机导航两项主入口和“更多”可触摸、可键盘操作；次要页面仍能进入。
- 我的任务与项目列表无需横向滚动即可读标题与状态，并可打开详情。
- 手机项目任务默认列表，桌面仍默认看板；手动切换有效。
- 现有权限、筛选、分页、创建、保存和通知流程不回退。
