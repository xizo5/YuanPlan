# 任务日历与时间线

用户已确认：在项目任务模块增加日历和时间线，点击任务进入现有详情抽屉修改日期并手动保存。

## 页面与交互

- 任务视图切换为看板、列表、日历、时间线；共用搜索、状态、执行人、优先级、标签、截止日期与隐藏子任务筛选。
- 切换视图保留筛选，URL 记录视图、日期及时间线刻度；关闭详情后保留原视图和日期。
- 日历为周一开始的月历，支持上/下月及回到今天。区间任务跨日期展示，跨周分段延续。每天最多展示三层任务，更多任务在当天弹窗中查看。
- 手机月历用日期、状态点和数量展示，点击日期打开当天任务；时间线在自身容器内横向滚动。
- 时间线左侧固定任务信息，右侧为日期刻度和任务条，支持日/周刻度、上/下一段时间、日期选择及回到今天。子任务缩进显示，父任务日期独立维护。
- 开始/截止都有：显示包含首尾日期的区间；只有一个日期：明确展示“开始”或“截止”日期点；都没有：展示于可展开、可分页的“未排期任务”。
- 状态色与现有任务模块保持一致；所有任务按钮打开相同详情，保存后刷新当前日期视图。
- 沿用项目权限、只读和归档限制，不引入拖动排期、日期自动保存、依赖关系或自动推算父任务日期。

## 数据与实现

- 复用现有 startDate / dueDate，不需数据库迁移。
- 提取公共任务查询条件，日历、时间线与现有任务列表使用同一套筛选。
- 新增项目内任务排期读取接口，按可见日期范围的区间相交条件查询。单日期按点筛选；未排期独立查询，不计入月份区间。
- 每页最多 100 项，返回总数与下一页；数据未加载完整时显示加载数量和“加载更多”，避免静默只展示第一页。
- 返回轻量任务摘要，不传输富文本、附件和评论。日期范围限制在 120 天以内，无定时轮询。
- 按日期本身计算排布，使用 UTC 日期数学避开夏令时，今天取用户本地日期。
- 日历与时间线按需加载，使用 Mantine 与 CSS 实现，无新增图表依赖。

## 实施与验证

1. 共享日期校验、排期摘要类型与公共查询条件；实现排期接口。
2. 日期范围、跨周分段、任务条位置与层级排序工具；实现月历、日期弹窗、时间线及未排期列表。
3. 接入视图工具栏、URL 状态与现有详情刷新。
4. 验证区间相交、单日期、未排期、分页、权限与筛选；验证跨月/闰年/夏令时布局。
5. 浏览器检查切换、保存前后位置、日期导航、跨周/溢出、只读和手机展示；类型检查、构建及完整测试。
