# 紧凑工作空间界面

用户已确认：参考 Kaneo / Plane，统一紧凑布局，保留绿色强调色。

- 删除重复英文眉题、宣传副标题、顶部口号；真实项目描述有值才显示。
- 项目首页使用紧凑行式布局，名称、任务完成量、进度、状态对齐。
- 项目任务使用单行工具栏；筛选条件在可展开面板中编辑并显示数量，支持清空。
- 看板保留拖动与键盘操作，缩小卡片间距；列表使用独立行式布局，展示编号、标题、状态、优先级、执行人、截止日期，保留子任务与分页。
- 统一文档、成员、团队、设置和空状态的边距、字号、圆角；必要说明和权限提示保留。
- 小屏允许工具栏换行、表格水平滚动，保留操作入口与可见焦点。

实施顺序：主题与框架 → 项目行 → 筛选与任务行 → 其他页面 → 类型检查、测试、构建及浏览器检查。

当前目录无 Git 仓库，设计文档直接保存在工作区。未找到 writing-plans 技能，以本文记录执行计划。
