# 项目概览

## 已确认的范围

用户已确认只做单个项目内部的进度概览，采用项目成员共用的布局，由项目管理员配置。保持轻量，手动保存配置和刷新数据。

## 页面与布局

- 在项目内部增加“项目概览”标签页，保留现有任务页面入口与默认行为。
- 顶部固定显示主任务总数、已完成、未完成和逾期任务，数字可进入对应任务列表。
- 默认四个模块：任务状态分布、未完成任务优先级、人员待办分布、需要关注的任务。
- 可选增加“未来 7 天到期”和“未分配任务”，形成最多六个预设组件。
- 提供 1、2、4、6 个模块模板；允许保留 3、5 个模块。单列或双列，组件可占满一行，手机固定单列。
- 配置面板支持添加、移除、上下移动、调整宽度；管理员点击“保存布局”后才持久化。成员和只读成员查看同一套布局，归档项目只读。
- 空项目展示真实的零值和空状态；加载和失败状态可见且可重试。

## 统计口径

- 所有概览数字、图表和跳转默认以当前项目未删除、未归档的主任务为单位。
- 完成率为已完成主任务数 / 主任务总数，明确称“任务完成率”，不代表工作量完成比例。
- 优先级和人员分布统计未完成任务；未分配任务保留独立分组。
- 逾期：未完成且截止日期早于当天。即将到期：未完成且截止日期为当天至未来第七天（包含边界）。
- 需要关注：逾期、未来 7 天到期、未完成高/紧急任务的并集，一个任务只展示一次。
- 日期按查看者所在时区计算，接口返回统计日期与数据时间；跳转携带同一统计日期，保证数字与列表匹配。

## 接口、存储与权限

- `GET /api/projects/:projectId/overview` 返回布局、聚合数字、分组和有界任务摘要。遵循现有项目读取权限和凭据范围。
- `PUT /api/projects/:projectId/overview/layout` 仅项目管理员可写，复用项目锁、版本冲突、幂等凭据、维护模式和审计。
- 新建 `project_overviews` 表，每个项目最多一条布局记录。尚未配置时只返回默认值，不因读取写数据库。
- 服务端直接聚合，不下载全部任务。一次概览请求完成统计，在进入页面和点击刷新时读取，无定时轮询。
- 任务列表增加未完成/关注范围筛选，复用日期与关注条件，支持概览下钻及既有分页。
- 不新增图表依赖，通过现有 Mantine 组件和轻量 CSS 展示环形图、条形图及可点击列表。

## 实施顺序与验证

1. 扩展共享类型与布局校验，新增数据库迁移和统计/配置服务。
2. 接入概览接口、统一任务关注筛选、补充权限与统计边界测试。
3. 实现概览组件、配置面板、项目标签页和任务列表跳转。
4. 类型检查、构建、测试；浏览器验证图表跳转、布局保存/取消/冲突、只读权限、空状态和手机宽度。

不在本版加入跨项目汇总、个人布局、历史趋势或任意图表编辑器。
